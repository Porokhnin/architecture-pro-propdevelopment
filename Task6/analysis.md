# Отчёт по результатам анализа Kubernetes Audit Log

## Подозрительные события

1. Доступ к секретам:
   - Кто: system:serviceaccount:secure-ops:monitoring
   - Где: kube-system
   - Почему подозрительно: доступ к секретам мониторингом

2. Привилегированные поды:
   - Кто: system:serviceaccount:secure-ops:monitoring
   - Комментарий: Создание привилегированного пода. При установленном флаге privileged среда выполнения контейнеров предоставляет полный доступ к файловой системе хоста, что делает этот параметр чрезвычайно опасным с точки зрения безопасности.

3. Использование kubectl exec в чужом поде:
   - Кто: system:serviceaccount:secure-ops:monitoring
   - Что делал: изменение coredns

4. Создание RoleBinding с правами cluster-admin:
   - Кто: system:serviceaccount:secure-ops:monitoring
   - К чему привело: создание ServiceAccount у которого права cluster-admin, который может управлять кластером.

5. Удаление audit-policy.yaml:
   - Кто: admin
   - Возможные последствия: отключение аудита действий пользователей.

## Вывод

Необходимо ужесточить политики доступа. Выделить соответствуюшие роли и минимальные права.
Настроить мониторинг и предупреждение о подозрительных действиях
