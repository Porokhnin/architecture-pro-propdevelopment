Требования к безопасности:

| №   | Требования                                                                                                                               | Комментарий |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| **I. Управление доступом**                                                                                                                                   |
| 1   | Реализовать принцип минимальных привилегий при назначении ролей и прав доступа.                                                          |             |
| 2   | Вести журналирование всех операций доступа к системам и данным.                                                                          |             |
| 3   | Использовать системы аутентификации пользователей для доступа к системам.                                                                |             |
| 4   | Создать замкнутые контуры для подсистем, работающих с чувствительными данными.                                                           |             |
| 5   | Вести единый реестр учётных записей.                                                                                                     |             |
| 6   | Применять средства для отзыва прав доступа.                                                                                              |             |
| 7   | Использовать средства централизованного контроля доступа.                                                                                |             |
| **II. Безопасность данных**                                                                                                                                  |
| 1   | Использовать шифрование на уровне базы данных, файловой системы и при передаче данных по сети.                                           |             |
| 2   | Реализовать механизмы управления ключами шифрования.                                                                                     |             |
| 3   | Проводить регулярное резервное копирование данных. Хранить ли резервные копии в защищённых хранилищах.                                   |             |  
| 4   | Использовать средства или процессы анонимизации данных.                                                                                  |             |
| **III. Управление инцидентами**                                                                                                                              |
| 1   | Использовать систему мониторинга безопасности (SIEM) для корреляции событий и анализа аномалий в режиме реального времени.               |             |
| 2   | Настроить автоматические оповещения об инцидентах и подозрительной активности.                                                           |             |


Протоколы аутентификации и авторизации:
Сервисы должны поддерживать OAuth 2.0 Client Credentials или JWT для аутентификации.

Взаимодействие сервисов отображено на диаграмме контейнеров.
