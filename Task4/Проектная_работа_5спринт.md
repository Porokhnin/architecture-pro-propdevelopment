Исходя из структуры компании и правила наименьших полномочий, можно выделить пять неймспейсов, по одному неймспейсу на домен:
Сервисы для клиентов
Сервисы для собственников
Бухгалтерский учет
Хранилище данных
Умный дом

В каждом неймспейсе необходимо создать Role с правами на чтения и Role с полным доступом. 
И отдельно необходимо создать СlusterRole с правами на чтения и СlusterRole с полным доступом, выданной лидам DevOps. 

В организации можно выделить следующие группы:
Разработчики (developer)
Лиды группы разработки (teamlead)
Support-L2 (support-l2)
Devops - devops


| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| Role | Права на просмотр ресурсов домена (namespace). | Разработчики. |
| Role | Полный доступ на редактирование ресурсов домена. | Лиды групп разработки (namespace). |
| ClusterRole | Права на просмотр подов кластера. | Support-L2. |
| ClusterRole | Полный доступ на редактирование ресурсов кластера. | Devops |



kubectl create namespace clever-home

kubectl create serviceaccount clever-home-developer -n clever-home
kubectl create serviceaccount clever-home-teamlead -n clever-home

kubectl create serviceaccount support-l2
kubectl create serviceaccount devops

kubectl apply -f roles.yaml

kubectl apply -f roleBindings.yaml
